The Sorting Office

The web page only posts the letter. A worker, started by Clever Cloud next to the web server, takes each job from a Redis queue. A failed job comes back after a pause, and after three failures it goes to the dead letter office. Every minute, cron prints a report.

          The minute report

          Clever Cloud runs clevercloud/cron.json on every instance. Each run asks Redis for the lock of its minute with SET … NX: the first one prints the report, the others stand down.
